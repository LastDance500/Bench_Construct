# Bench Outputs

`v1.1/` contains the final OntoURL v1.1 CSV export and release metadata:

- 15 task CSV files
- `manifest.json`
- `task_counts.csv`
- `domain_counts.csv`
- `capability_counts.csv`
- `upload_counts.csv`
- `upload_summary.json`

Generated intermediate files from local construction runs should be written to
task-specific subdirectories under `bench/`.
